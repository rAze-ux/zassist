# ZAssist — ИИ-ассистент для iPhone (на русском)

Приложение, через которое вы общаетесь с ИИ (модели GLM через Z.AI):
проекты-чаты синхронизируются между устройствами, вход по аккаунту, весь
интерфейс на русском.

**Как это устроено:**

- **Приложение** — SwiftUI, iOS 16+, без сторонних библиотек
- **Аккаунты и синхронизация** — Supabase (бесплатный тариф)
- **ИИ** — API Z.AI по вашему ключу, ответ приходит потоком (печать по мере генерации)
- **Сборка .ipa** — GitHub Actions на macOS-раннере; Mac не нужен
- **Установка** — Sideloadly на Windows + ваш Apple ID (бесплатно)

---

## Шаг 1. Репозиторий на GitHub

1. Создайте репозиторий на github.com (кнопка **New repository**).
   **Рекомендую публичный** — тогда macOS-раннеры бесплатны и без лимитов
   (для приватного macOS-сборка тратит минуты в 10 раз быстрее).
2. Загрузите этот проект в репозиторий, например из папки проекта:

   ```
   git init -b main
   git add -A
   git commit -m "ZAssist: первое приложение"
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПО.git
   git push -u origin main
   ```

## Шаг 2. Supabase — аккаунты и синхронизация

1. Зайдите на **supabase.com** → **Start your project** → создайте проект
   (бесплатный план, нужен только email).
2. Дождитесь, пока проект создастся (~1–2 минуты).
3. Откройте **SQL Editor** → **New query** → вставьте содержимое файла
   [`supabase/schema.sql`](supabase/schema.sql) → **Run**. Должно быть
   «Success. No rows returned».
4. **Рекомендуется:** Authentication → Sign In / Providers → Email →
   выключите **Confirm email**, чтобы регистрация была мгновенной
   (иначе придётся подтверждать почту при регистрации).
5. **Project Settings → API**: скопируйте два значения:
   - **Project URL** (вида `https://abcdefgh.supabase.co`)
   - **anon public key** (длинная строка)

   Они понадобятся при первом запуске приложения.

## Шаг 3. Ключ Z.AI (модели GLM)

1. Зайдите на **z.ai** → консоль/профиль → **API Keys** → создайте ключ.
2. Проверьте баланс: у новых аккаунтов обычно есть стартовый кредит;
   самая дешёвая модель — `glm-4-flash`, самая умная — `glm-4.6`.

## Шаг 4. Сборка .ipa (автоматически)

1. Откройте ваш репозиторий на GitHub → вкладка **Actions**.
   При первом входе нажмите **I understand my workflows, go ahead and enable them**.
2. Сборка запустится сама от каждого push, либо запустите вручную:
   слева **Build IPA** → **Run workflow** → **Run workflow**.
3. Через ~5–10 минут откройте законченный запуск → внизу в разделе
   **Artifacts** скачайте **ZAssist-ipa** → распакуйте zip, внутри
   `ZAssist.ipa`.

   > IPA собирается без подписи — это нормально. Подпись ставится
   > на следующем шаге вашим Apple ID через Sideloadly.

## Шаг 5. Установка на iPhone (Sideloadly, Windows)

1. Установите на ПК приложение **Apple Devices** из Microsoft Store
   (или iTunes) — нужны его драйверы.
2. Скачайте **Sideloadly** с [sideloadly.io](https://sideloadly.io) и установите.
3. Подключите iPhone кабелем к ПК, разблокируйте его и при запросе
   нажмите **Доверять** этому компьютеру.
4. В Sideloadly: перетащите `ZAssist.ipa` в окно, введите ваш
   **Apple ID** и пароль.
   - Если включена двухфакторная аутентификация, нужен **пароль приложения**:
     зайдите на [account.apple.com](https://account.apple.com) →
     «Учётная запись» → «Безопасность» → «Пароли приложений» → создайте.
5. Нажмите **Start**. После установки на iPhone: **Настройки → Основные →
   VPN и управление устройством** → ваш Apple ID → **Доверять**.
6. Открывайте ZAssist!

**Ограничение бесплатного Apple ID:** приложение живёт **7 дней**, потом
просто повторите установку через Sideloadly (данные не теряются — всё в Supabase).

## Шаг 6. Первый запуск

1. На экране **«Настройка»** вставьте Project URL и anon-ключ из Шага 2.
2. Переключитесь на **«Регистрация»**: email + пароль (минимум 6 символов).
3. Вкладка **«Настройки»** → вставьте **API-ключ Z.AI** из Шага 3, выберите модель.
4. **Проекты** → «+» → напишите первое сообщение. Ответ печатается потоком.

История хранится в вашем Supabase: с другого iPhone достаточно войти в тот
же аккаунт — проекты подтянутся сами.

## Если что-то не так

| Симптом | Причина и решение |
|---|---|
| «Приложение не настроено» | Не введены или неверны URL/anon-ключ Supabase (Настройки → Supabase) |
| «Неверный email или пароль» | Проверьте раскладку/регистр; либо вы регистрировались при включённом подтверждении email |
| «Ошибка API Z.AI (код 401)» | Неверный API-ключ или не привязан способ оплаты |
| «Ошибка API Z.AI (код 429)» | Слишком частые запросы / нет баланса |
| «Ошибка сервера Supabase (код …)» | Не выполнен schema.sql, либо anon-ключ от другого проекта |
| Actions не запускается | Включите workflows во вкладке Actions; проверьте, что push был в ветку `main` |
| Приложение перестало открываться через 7 дней | Переподпись через Sideloadly — это ограничение бесплатного Apple ID |

## Как менять приложение

Весь код — в папке `ZAssist/` (экраны в `ZAssist/Views/`), схема сборки —
`project.yml`, CI — `.github/workflows/build-ipa.yml`. Внесли изменения →
push → скачали свежий IPA из Actions → переустановили через Sideloadly.

Сборка на Mac (если появится): `brew install xcodegen && xcodegen generate`
и открыть `ZAssist.xcodeproj` в Xcode.

## Структура

```
├── project.yml                  # описание Xcode-проекта (XcodeGen)
├── .github/workflows/build-ipa.yml  # CI: сборка unsigned .ipa на macOS
├── supabase/schema.sql          # таблицы + политики доступа (RLS)
└── ZAssist/
    ├── ZAssistApp.swift         # точка входа
    ├── AppState.swift           # состояние: сессия, проекты, настройки
    ├── SupabaseService.swift    # вход/регистрация + REST (синхронизация)
    ├── AIService.swift          # Z.AI: потоковые ответы GLM
    ├── Keychain.swift           # хранение секретов
    ├── Models.swift             # модели данных
    ├── Config.swift             # значения по умолчанию
    └── Views/                   # экраны (настройка, вход, проекты, чат, настройки)
```

## Безопасность

- **anon-ключ Supabase** публичный по дизайну: доступ к данным защищают
  RLS-политики (каждый видит только свои проекты и сообщения).
- **API-ключ Z.AI** хранится только в Keychain вашего iPhone и уходит
  напрямую в Z.AI, минуя чужие серверы.
- Пароли не хранятся в приложении — за них отвечает Supabase Auth.
